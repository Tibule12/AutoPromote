# Native masks, crop animation and delivery-resolution graphics

Three shared Studio repairs are implemented on the existing isolated branch.
This is bounded S02 engineering work, not a creative showcase or AE completion.

The composition compiler now transports authored mask settings. The existing
image/title compositor evaluates crop keyframes on the edit clock, preserves the
object-fit box and clips the filtered group before rotation. Static image masks
also take this compositor path. Rectangle, ellipse and percentage-polygon masks
retain the existing preview's shape/crop precedence; these are deterministic
geometry, not AI segmentation.

Title masks now use the actual text layout box, excluding the renderer's shadow
padding. Finally, when delivery exceeds source resolution, the renderer scales
the source before drawing ordinary graphics. Previously, a 320×240 source could
make a 720p title visibly soft by rasterizing the title at 240px and enlarging the
completed composite. Source-sized exports preserve their native dimensions.
