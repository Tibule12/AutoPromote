## Why measurement changed

The initial ordinary Analytics audit found **133 published platform posts in seven days**, all previously presented as zero despite absent collection. The signed-in bounded refresh read six real recent posts. YouTube supplied 3 views/1 like/0 comments; Instagram supplied 0 likes/0 comments but no views; Reddit supplied 0 comments but no view count. LinkedIn, Facebook and TikTok returned no usable counters in that check. These are partial observations, not an account-wide view count or evidence of a platform penalty.

The shared analytics path now preserves missing counters as unavailable, keeps impressions separate from video views and Reddit score separate from likes, reports collection coverage and last actual success, and avoids an ungrounded combined CTR. New post records initialize collection. A bounded owned refresh has a five-minute per-post cooldown and no publishing side effects. Quiet posts retain the 48/72-hour collection windows instead of stopping at 24 hours below 20 views. Legacy records need an explicit refresh.

Published-release selection scopes both the view and refresh targets. Newest-post selection is independent of performance-ranked display. Request generation/scope guards prevent late account responses from replacing a selected release. **21 backend tests and 4 UI tests pass**, as do strict local builds and actual signed-in refresh/filter checks. These changes are local branch work; no public backend/frontend deployment is claimed.
