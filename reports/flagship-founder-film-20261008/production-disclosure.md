# What this production actually uses

The story, script, art direction and templates are directed by the coding assistant under the founder’s brief. This is a private, bespoke production; it does not establish arbitrary-brief autonomous customer movie creation.

New picture assets are rendered by AutoPromote’s existing NVIDIA Blender runtime from editable scene geometry, cameras, materials, lights and motion. The original A/P mark comes from its existing authored Bézier geometry. Brand geometry stays reusable, with native scenes retained. The final sequence graphic uses the film’s planned shot order beside an archived Studio image; it is not a recording of this new project open in the customer UI.

The moving ocean/yacht source is a retained actual Wan 14B generated take from 7 October, not a new video-model generation in this session. Conversation stills and the Studio image are retained product/development material. They illustrate the origin; they are not a reenactment of the founder’s life. GPU labels are art-directed summaries of saved evidence, not fabricated emails or live cloud-console recordings. The September L4 denial and October RTX quota grant are distinct events. 3000 milliGPU is regional allocation capacity; it does not mean 3000 physical GPUs.

New narration uses the retained Kokoro-82M model on CPU and the standard af_heart preset. It does not clone or represent the founder’s real voice. Score and sound cues are original deterministic synthesis, with editable notes and event timing, also on CPU.

The actual final AAC exports are mono despite stereo source score/cue stems. The independent audio audit records their true channel count and replaces an earlier measurement that forced a stereo decode. The source generator being stereo does not establish stereo delivery. The hero picture is 53.833333 seconds against a 53.75-second plan; the two-frame difference is current renderer segment rounding.

Accepted asset bytes must be hashed and reviewed before the private Factory compiler constructs intelligence evidence, Director trim commands and a canonical Studio project. Final assembly uses the current Studio RenderViralRequest/render_viral_clip_impl renderer. Only its private artifact storage transport is substituted. Renderer receipts identify actual encoders and source bytes; no cloud credentials are copied into this production runtime.

The ending’s created-by statement refers to the generated sources and actual AutoPromote assembly/render. It should not be read as a claim that the application independently conceived the entire creative direction or that all ordinary customer generation entry points are released.
