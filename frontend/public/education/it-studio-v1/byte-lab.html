The program checks before it converts.

function convert(value) {
  if (!Number.isInteger(value) ||
      value < 0 || value > 255) {
    return "Enter a value from 0 to 255";
  }
  return value.toString(2).padStart(8, "0");
}

The input is parsed as a number first. Padding keeps all eight bit positions visible.
