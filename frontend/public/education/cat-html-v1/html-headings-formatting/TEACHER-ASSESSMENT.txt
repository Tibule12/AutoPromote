REASONING GUIDE
Is bold paragraph text equivalent to h2?
No. b changes presentation; h2 identifies a heading level in the document structure.

Does the file break when h2 is changed to h1?
It can still render. The example loses the intended top-level/subordinate distinction; this is a structural/design problem rather than necessarily a loading error.

Why can an underlined word be confusing?
Readers may expect underlined text to be a link. Underline by itself does not add href or navigation.
