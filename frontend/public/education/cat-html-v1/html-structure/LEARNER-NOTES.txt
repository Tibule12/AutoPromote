A document has metadata in head and visible content in body. title names the browser tab; h1 is the visible main heading. Paragraph and formatting tags change the displayed content. Closing tags nest in reverse order.

Before editing: open index.html in a browser. Open the same file in a plain text editor. Save changes, reload the browser and compare. The source recording contains a real browser iframe; its page zoom is 150% for readability. Code and output are shown simultaneously. The teacher can use the standalone files without Studio.
