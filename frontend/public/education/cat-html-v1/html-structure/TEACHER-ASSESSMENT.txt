REASONING GUIDE
If title changes to Music Club but h1 stays Code Club, what changes?
The document/tab title changes; the visible h1 stays Code Club. They are separate elements.

Why does <p><b>Friday</p></b> need repair?
The elements are improperly nested. Close b before p: <p><b>Friday</b></p>. Browser error recovery is not a substitute for correct source.

Does h1 simply mean “make text big”?
It identifies a top-level heading. Default browser styling makes it large; heading hierarchy communicates structure.
