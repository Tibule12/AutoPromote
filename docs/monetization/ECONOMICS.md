The current implementation, cost inventory, fresh read-only infrastructure observations and reproducible 30-scenario calculator are in [the implementation report](../../reports/free-first-20261126/README.md). Historical October observations remain in this directory; they are not current workload invoices.

Run `npm run free-first:economics`. Inputs are integer USD microdollars and explicit confidence/basis fields in `config/free-first-economics.example.json`. Replace estimates with attributable provider invoices, billing-export rows and operation telemetry when available. The calculator includes payment fees, processing, storage, network, fixed costs, margins, break-even conversion, subsidy and maximum exposure for 100–1,000,000 users at 0/1/3/5/10/20% conversion. Advertising and investment are zero in the baseline.

The $4.99 Plus proposal is not financially validated. An illustrative $0.08 average Free total is a target scenario, not a measured achievement. Free $0.50 and Plus $2 processing ceilings exclude separately modeled storage/network/fixed overhead. Without conversion there is no subscription revenue, so subsidy is required even at low processing cost.

Cloud rates are reference inputs, never operation measurements. A fresh GET-only audit found a 4-vCPU/8-GiB media service and a 20-vCPU/80-GiB Cam Combiner GPU job with a four-hour timeout. It found no accessible BigQuery datasets; billingInfo was denied. Aggregate instance/CPU/memory seconds cannot be divided by request counts to establish a per-operation charge. Local CPU renders prove bounded functionality and resource timing; they do not measure cloud startup, GPU or API invoices.

Sources verified during this work: [Cloud Run billing/rates](https://cloud.google.com/run/pricing), [PayPal merchant fees](https://www.paypal.com/za/business/paypal-business-fees). Confirm this merchant's actual country, cross-border, currency and provider fee agreement before approving price. The example 4.4% + $0.30 fee is a sensitivity assumption, not an assertion of the account's rate.

WebCodecs, workers/WASM, WebGL and WebGPU need feature and preview/export parity qualification before replacing working production paths.
