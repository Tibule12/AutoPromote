# Start with an owned editable project

Development documentation • product 1.2.0 • knowledge 1.0.18 • 2026-10-15

Readiness is scoped to each entry. FUNCTIONAL does not mean professional or production ready. Current account permissions, source ownership and execution availability remain authoritative.

1. Sign in through the existing account flow and import owned supported sources.
2. Open Studio and inspect the native timeline. A cut already inside imported footage is different from a new clip occurrence.
3. Apply an exact draft template or edit ordinary clips/layers/audio. Director proposals require evidence and review; manual editing uses the same project.
4. Save, reopen and inspect current source bindings, timing and keys.
5. Render the current revision and watch the full exported movie with sound. Check the relevant limitations before publishing.

Model-backed features require current execution availability, costs/authorization and owned reviewed artifacts. Browser placement studies do not qualify as segmentation, tracking, cleanup or replacement output.
