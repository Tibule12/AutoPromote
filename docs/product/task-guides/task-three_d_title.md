# Create a 3D title/logo scene

Development documentation • product 1.2.0 • knowledge 1.0.19 • 2026-10-15

Readiness is scoped to each entry. FUNCTIONAL does not mean professional or production ready. Current account permissions, source ownership and execution availability remain authoritative.

ID: `task.three_d_title` • **PARTIAL** • SUPPORTED_WITH_LIMITATIONS

Use supported bounded scene fields, then obtain and review a current owned final 3D result.

## Before you start

- system.account — FUNCTIONAL

## Steps

1. Choose a scene preset and edit title/material plus supported transform values.
   Feature: `studio.three_d`. Controls: [studio.three_d.material](../control-reference/index.md#studio-three_d-material), [studio.three_d.x](../control-reference/index.md#studio-three_d-x), [studio.three_d.rotationy](../control-reference/index.md#studio-three_d-rotationy).

2. Adjust camera focal length/light intensity; disabled fields do not gain final support.
   Feature: `studio.three_d`. Controls: [studio.three_d.focallength](../control-reference/index.md#studio-three_d-focallength), [studio.three_d.lightintensity](../control-reference/index.md#studio-three_d-lightintensity).

3. Request the existing final scene path only under its availability and cost checks, then review and compose the owned result.
   Feature: `studio.blender`.

## Feature readiness

- system.costs — **PARTIAL**: Exposed generation/render workflows display estimates and apply account allowances or charging checks. A local development charging bypass is not evidence of production billing.
- studio.three_d — **PARTIAL**: Authors bounded 3D scenes and renders them through the existing 3D worker path. Supported transforms are approximate across browser and final render, and several displayed fields are disabled for final output.
- studio.blender — **PARTIAL**: Renders supported authored scenes to owned output for the canonical composition. A browser WebGL preview alone is insufficient to qualify the final scene.

## Result and limitations

An owned editable result with current revision and reviewed output; inspect the actual moving picture and sound.

- Follow the linked feature readiness; these steps do not promote the workflow to professional or production readiness.

Troubleshooting references: system.unsupported_media, studio.revision.
